LinuxFlashcard — Debian 13 / XFCE

ЗАПУСК В WINDOWS
Откройте run-linux.bat на флешке двойным щелчком в Проводнике.
Обычный режим TCG запускается без прав администратора Windows.
Используются UEFI и автоматический выбор до 2 CPU.

Память Linux подбирается автоматически: свободная RAM минус 2048 МиБ
резерва Windows/QEMU. Минимум гостя — 320 МиБ; для такого запуска
перед стартом нужно не менее 2368 МиБ свободной RAM.
320 МиБ проверены для базового сеанса XFCE с редактором;
IDE, браузеру и серверам требуется больше памяти.

РАБОЧИЙ СТОЛ
Имя пользователя: student. Используйте свой пароль Linux.
Ctrl+Alt+T — терминал.
Super+E или Ctrl+Alt+F — файловый менеджер Thunar.
Alt+F2 — поиск/запуск приложения, например mousepad.
Mousepad — редактор текстовых файлов; Ctrl+S сохраняет документ.
Alt+Shift — переключение английской и русской раскладок по умолчанию.
Личные настройки раскладки XFCE имеют приоритет над системными.

ДАННЫЕ
Linux, установленные программы, настройки и документы сохраняются
в общем файле linux.img.vtoy на флешке.
QEMU и нативная UEFI-загрузка используют одну систему и одни данные.
Перед сменой режима штатно выключайте Linux.
Существующие Desktop и другие пользовательские каталоги
не переименовываются при смене языка интерфейса.

ВЫКЛЮЧЕНИЕ
Сохраните документы и выберите в меню XFCE «Завершить сеанс» → «Выключить».
При запуске через Windows дождитесь закрытия окна QEMU,
затем можно отключать носитель или копировать образ.
При ошибке запуска сохраните сообщение; путь журнала напечатан в окне.
Журналы запуска Windows находятся в каталоге logs рядом с run-linux.bat
на флешке.

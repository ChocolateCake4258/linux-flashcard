LinuxFlashcard — аппаратно-ускоренный запуск в Windows

ЗАПУСК
run-linux-accelerated.bat открывает ту же систему linux.img.vtoy через WHPX
(Windows Hypervisor Platform). Пользователь, пароль, программы и данные общие
с run-linux.bat и нативной UEFI-загрузкой.

На подготовленном компьютере для запуска WHPX обычно достаточно обычных прав.
Если WHPX недоступен, запустите enable-acceleration.bat: первоначальное включение
компонента Windows требует администратора/UAC. Скрипт не перезагружает ПК сам.
Если попросит — сохраните работу и перезагрузите Windows самостоятельно.
В UEFI/BIOS должна быть включена виртуализация AMD-V/SVM или Intel VT-x.

ПРОФИЛЬ
По умолчанию RAM гостя — максимум текущей свободной RAM минус 2048 МиБ резерва
Windows/QEMU, с точностью до одного МиБ. Минимум Linux 320 МиБ, прежних caps
4/6 ГиБ и половины total RAM нет. CPU WHPX — до 4, не более половины логических CPU.
Можно задать ресурсы при запуске, например:
    run-linux-accelerated.bat -RamMb 4096 -Cores 2
или:
    run-linux-accelerated.bat -RamMb 6144 -Cores 4

Обычная кнопка TCG использует тот же RAM-бюджет, до 2 vCPU.
Явный небольшой профиль:
    run-linux.bat -RamMb 512 -Cores 1
Значение 0 означает авто-подбор. Для 320 МиБ гостю нужно минимум 2368 МиБ
СВОБОДНОЙ RAM перед стартом, включая резерв 2048 МиБ.
Примеры auto: свободно 2429 -> Linux 381; свободно 3030 -> Linux 982 МиБ.
320 МиБ — предельный базовый сеанс с редактором, не профиль тяжёлых IDE.
В RC9 параметры пользователя больше не дублируются defaults внутри BAT.

WHPX ускоряет выполнение CPU. Дисковые операции на флешке и 3D-графика зависят
от оборудования отдельно; этот режим сохраняет стандартный 2D VGA 1024x768/60.
При недоступном WHPX ускоренный запуск выдаёт ошибку, а не скрыто включает TCG.
run-linux.bat остаётся обычным программным режимом TCG без настройки гипервизора.

ЖУРНАЛЫ И ДАННЫЕ
Журналы: каталог logs рядом с запускателями; в launch-profile.json поле Accel=WHPX.
whpx-status.json показывает результат проверки API гипервизора.
WHPX и TCG используют один image lock и одни постоянные UEFI VARS.
Завершайте Linux через «Выключить», прежде чем менять режим запуска.

run-from-usb.bat — общая оболочка PowerShell, которую вызывают обе кнопки.
Она передаёт параметры и показывает ранние ошибки. Удалять её из комплекта нельзя.

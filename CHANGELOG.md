# Изменения

## 2026.10.22-rc7

- Публичный репозиторий переведён на проверенный Debian/XFCE-конвейер и сценарий
  START → сборка → запись USB → полная проверка. Прежний Kubuntu-код доступен в истории.
- Добавлены MIT LICENSE, версия выпуска, инструкции разработчика и публичная сводка
  приёмки без локальных отчётов стенда.
- CI проверяет исходники, shell scripts, Windows PowerShell5.1 contracts и упаковку.
  По тегу v<VERSION> собирается пользовательский Windows ZIP с SHA256 для GitHub Release.
- Native launcher tests используют управляемые resource fixtures и отдельно
  проверяют отказ при недостаточном резерве памяти.

## 2026.10.22-rc6

- Конвейер можно сохранить вместе с проверенными входами и чистой подготовленной
  заводской основой: ZIP64 capsule, SHA manifest, автономный REBUILD одной кнопкой.
- Копия основы получает новую build identity и повторно проходит функциональные
  и direct/Ventoy/direct проверки. Версии пакетов закреплены; сеть при восстановлении
  из capsule запрещена, отсутствующие входы не подменяются новыми загрузками.
- На рабочем столе выпуска больше не создаются текстовые листы с проверками.
  Экран первого пароля очищается и содержит обычное приглашение настройки.

## 2026.10.22-rc5

- Файловый запуск TCG/WHPX использует те же PCI-адреса диска/сети, что и фабрика,
  и явный bootindex системного диска. Существующий UEFI VARS сохраняется; переход
  в EFI Shell из-за добавления диска после Shell в BootOrder устранён.
- Сеанс, завершившийся в UEFI Shell без признаков загрузки Linux, теперь сохраняет
  ошибку этапа uefi-boot, даже если сам QEMU вернул код0.

## 2026.10.20-rc4

- Перед удалением USB layout проверяется физическое чтение границ носителя.
- Добавлена проверяемая нормализация synthetic whole-device view после удаления
  GPT: только при пустой таблице, отсутствии GPT/томов/точек доступа и точной identity.
- Ошибки raw write/read-back или повторной enumeration не засчитываются как готовая
  разметка; при устойчивой ошибке устройства сообщается о переподключении, образ сохраняется.
- Если Windows блокирует raw write в synthetic view с NOT_READY, используется
  guarded native empty GPT без разделов. Disk identity, обе GPT/CRC и пустота таблиц
  проверяются до записи тела; уже пустая разметка повторно не удаляется.
- Размер цели в журнале берётся из проверенного Get-Disk, а не устаревшего CHS/WMI.

## 2026.10.19-rc3

- Compact storage по умолчанию: проверяемая уборка ISO staging и standalone RAW/VARS.
- Публикация fixed VHD как RAW на месте с footer/GPT/SHA checks и восстановлением
  после прерывания rename/truncate/publish. Второй большой итоговый файл не создаётся.
- Для 32-ГБ USB рекомендуется 70 GB вместо 100 GB. KeepIntermediates сохраняет
  прежний режим; storage policy и сохранённые receipts защищают обычный Resume.

## 2026.10.19-rc2

- Чистый пользовательский ZIP: START, CHECK и BUILD-IMAGE в корне, актуальные
  инструкции, только необходимые установочные файлы и Linux-примеры.
- Рабочее хранилище по умолчанию на диске распакованного проекта; без неявного
  выбора системного диска. Временные файлы и профили процессов локализованы.
- Проверка комплектности пользовательского пакета доступна без Python/интернета.

## 2026.10.18-rc1

- Единый Debian 13/XFCE factory pipeline с полным учебным набором, проверенными
  входами, source snapshots, resume и direct → Ventoy → direct proof.
- `build-all.bat`: выбор USB, автоматический workspace, capacity-matched image,
  запись и полный read-back с проверяемой receipt.
- Общий постоянный образ на NTFS, portable QEMU 11.1.2, обычный TCG и отдельный
  WHPX с явной настройкой и Windows resource reserve.
- Потоковые ZIP64-копии Linux-комплекта, SHA256 всех файлов, проверка архива,
  восстановление в новый каталог и защита от копирования запущенного образа.
- Совместимые файловые пути QEMU для каталога комплекта с кириллицей, пробелами
  и скобками; original path/working directory/backend paths фиксируются в profile.
- Проверяемый source-only release ZIP с manifest и нормализованными metadata.
- Windows regression, factory/coordinator, backup corruption/round-trip и
  release reproducibility tests; Windows CI запускает эти проверки.

Инструкция основного сценария: `ИНСТРУКЦИЯ.md`.

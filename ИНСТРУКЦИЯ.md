# Подготовка Linux-флешки

## 1. Распаковка и проверка

Распакуйте **весь** архив на локальный NTFS-диск. Для 32-ГБ флешки на нём должно
быть около 70 ГБ свободного места. Запустите `CHECK.bat`: проверка не скачивает
ОС и не выбирает физический носитель.

## 2. Автоматическая подготовка

Подключите тестовую USB от 32 ГБ и откройте `START.bat`. Выберите номер в
квадратных скобках, сверяя модель и serial. Ввод `yes` разрешает стереть выбранный
носитель после сборки. Подтвердите UAC и оставьте окно открытым до результата.

Скрипт скачает и проверит входные файлы, подготовит Debian/XFCE и учебные программы,
проверит приложения и общие данные через direct → Ventoy → direct, затем запишет USB
и проверит её чтением. QEMU и кнопки запуска уже включены в образ.

## 3. Продолжение и новая сборка

Повторный `START.bat` подхватывает сохранённую сборку. Подключите тот же USB.
Если запись была прервана, она начнётся заново из проверенного образа.
Готовая USB повторно не стирается без `-Rewrite`.

Проверенные промежуточные файлы удаляются автоматически после завершения следующего
этапа. Состояние, ISO, кэш и готовый образ сохраняются. Для обновления исходников
после assembly начинайте новую сборку; прежний snapshot остаётся фиксированным.

```bat
START.bat -Status
START.bat -NewBuild
START.bat -Rewrite
START.bat -Workspace E:\LinuxFlashcard-new
```

Для полного выпуска только файла-образа используйте `BUILD-IMAGE.bat`.
Он проходит те же проверки Linux, но не открывает физический USB на запись.

## 4. Первый вход

После подготовки безопасно извлеките USB. Для запуска из Windows откройте
`run-linux.bat` или `run-linux-accelerated.bat` с самой флешки. При первом старте
задайте пароль для student на локальном экране Linux; затем откроется LightDM.
Для нативного режима выберите USB в UEFI boot-меню совместимого ПК.

В обоих режимах используется одна система. Создайте тестовый документ, штатно
выключите Linux и проверьте документ после повторного запуска и смены режима.

## 5. Где находятся данные

- рядом с распакованным проектом: `LinuxFlashcard-work` — сборки, загрузки, кэши;
- в workspace: `factory-state.json`, `jobs`, `artifacts` — состояние, логи и образы;
- на USB: `linux.img.vtoy` — система/проекты, `.uefi-vars.fd` — постоянная прошивка;
- на USB: `logs` — журналы обычного запуска.

Выбор диска сборки явный: по умолчанию диск распакованного проекта. Другой каталог
задаётся через `-Workspace`. Системный диск не выбирается автоматически.

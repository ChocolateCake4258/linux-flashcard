# Проверки и границы приёмки

Сводка испытаний Debian-ветки: RAM-пробы на 25 октября 2026, дополнительные
результаты из отчёта автора и сведения о публикации RC10 от 11 ноября 2026.
Локальные диагностические отчёты, идентификаторы устройств, персональные paths
и артефакты хранятся отдельно.

## Совместимость

| Конфигурация | Подтверждённый статус |
|---|---|
| Windows 10 x64 | Подготовка и файловый запуск проверены |
| QEMU: TCG и WHPX | Запуск обычным пользователем проверен |
| Нативная загрузка x86-64 UEFI | Загрузка и сохранение общих данных подтверждены |
| Учебные ПК без прав администратора Windows | QEMU и нативная загрузка проверены — согласно отчёту по работе |
| Windows 11, Secure Boot, Legacy BIOS | Требуют отдельных испытаний |

## Подтверждено

- Windows 10 x64, AMD Ryzen 5, 16 GiB RAM; файловые запуски обычным пользователем.
- TCG и WHPX; persistent Linux image/VARS, повторные запуски и штатное выключение.
- Нативный x86-64 UEFI и общие файлы после смены режимов подтверждены пользователем.
- По отчёту автора дополнительно проверены учебные ПК без прав администратора
  Windows: запуск в QEMU и нативная UEFI-загрузка завершились успешно.
- CLI/languages, IDE, PostgreSQL/SQLite, офис/математика, Docker и Wireshark:
  функциональные, persistence и GUI checks полного учебного набора.
- Исходный boot-to-Shell исправлен согласованными PCI paths и bootindex;
  shell-only exit0 сохраняется как ошибка загрузки.
- Реальная physical запись 32-ГБ USB с полным deferred body/boot-region read-back.
- Backup/restore stopped-комплекта с SHA, ZIP64, проверкой corruption и busy-image guards.
- Автономный RC6 capsule: независимая распаковка, Limited CHECK/Plan, полный новый
  десятиэтапный REBUILD с restricted guest network. 1439 package/version/status
  записей совпали с frozen factory base.
- RC6 seal: проверочные TXT на Desktop отсутствуют. Реальный consumer boot до
  обычного приглашения первого пароля, затем ACPI powerdown/exit0.
- Изолированные RAM-пробы той же установленной системы без swap: 320 МиБ guest
  повторяемо прошли базовый XFCE/Mousepad workflow (TCG 3/3, WHPX ещё 1/1),
  включая два трёхминутных hold. 304 МиБ дали один успех и неуспешный повтор,
  288 МиБ — OOM/timeout; 256 МиБ достигли обычного LightDM, но не прошли desktop
  workflow. Это предельный старт, не приёмка всех IDE/серверов на такой RAM.

## Автоматическая проверка

Linux CI: source encodings/syntax, ShellCheck, Python state/recovery/packaging
tests и сборка/проверка Windows ZIP. Windows CI: PowerShell 5.1, file-backed writer,
USB coordinator, backup и native launcher contracts. Прямые native disk calls
изолированы fixtures; CI не является записью настоящего USB или GUI-приёмкой Linux.

[выпуск 2026.10.25-rc10](https://github.com/ChocolateCake4258/linux-flashcard/releases/tag/v2026.10.25-rc10)

  [`90662f352d007a60b45361fb094c850a4a77175a`](https://github.com/ChocolateCake4258/linux-flashcard/commit/90662f352d007a60b45361fb094c850a4a77175a).

  всех 100 исходных файлов. Содержимое сверено с указанным коммитом с учётом

- После публикации проверено скачивание ZIP и SHA256 по публичным ссылкам;
  скачанный архив совпал с проверенным пакетом CI.

## Оставшаяся аппаратная матрица

- Windows 11, Secure Boot и Legacy BIOS.
- Дополнительные Intel/AMD машины и учебные ПК со стандартной учётной записью
  и различной готовностью WHPX для расширения проверенного набора оборудования.
- Контрольная физическая цепочка актуального опубликованного Windows-пакета:
  START из чистой распаковки → новая сборка → полная запись → пользовательская приёмка.

Для автономного RC6 ранее проверен полный повторный выпуск до файла-образа.
Результаты принятого рабочего носителя и испытаний на учебных ПК приведены выше.
Аппаратная проверка каждого нового опубликованного Windows-пакета фиксируется
отдельным прогоном.

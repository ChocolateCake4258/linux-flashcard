# linux-flashcard

Разработка универсального загрузочного носителя с предустановленным программным
обеспечением на базе Kubuntu Linux для учебных целей.

> Текущая версия — **v2**, переработка проекта с автоматизированной подготовкой
> носителя. Предыдущая версия доступна в истории репозитория и по метке `v1`.
> Два способа сборки:
> - **способ A** (Linux, bash): пересборка кастомного ISO — `make iso`;
> - **способ B** (Windows, рекомендуемый): одна команда `win\build-all.bat`
>   строит флешку **«два тома, одна система»** (нативная загрузка + QEMU-кнопка).

## Установленное ПО

- **ОС**: Ubuntu LTS (Kubuntu desktop, ru_RI.UTF-8, Москва)
- **Языки**: Python, Java, C/C++ (gcc/gdb/make), C# (.NET), Go, Rust, Node.js (+TypeScript)
- **Редакторы**: VS Code, Vim/Neovim
- **БД**: PostgreSQL, SQLite
- **Математика**: GeoGebra
- **Инструменты**: Git, Docker, Wireshark
- **Офис**: LibreOffice

## Способ B — флешка «два тома, одна система» (Windows, всё в один клик)

Требования: Windows 10/11, ~35 ГБ свободного места, интернет (~3 ГБ), флешка
**32 ГБ и больше**. Права администратора нужны только на этапе записи (UAC).

```
win\build-all.bat
```

Конвейер (стадии 0–9, можно продолжать после сбоя):

- 0 предпроверка (место/интернет), план;
- 1 portable QEMU (тихая установка при отсутствии);
- 2 загрузка live-server ISO с докачкой `curl -C -` и проверкой SHA256;
- 3 виртуальный диск `virtual-disk.qcow2` (28G);
- 4 `seed.iso` из `win\autoinstall.yaml`;
- 5 неинтерактивная установка Kubuntu в QEMU (UEFI, WHPX/TCG, сама выключается);
- 6 пробная загрузка установленного образа;
- 7 конвертация в `virtual-disk.img` (raw);
- 8 запись raw на флешку (UAC; защита от системного диска);
- 9 докладка на том P1 (`qemu\`, `run-qemu.bat`, доки).

Полезные параметры: `-FromStage 5` (продолжить с установки),
`-Force` (пересоздать артефакт стадии), `-ShowWindow` (окно QEMU),
`-NoSmoke`, `-Eject`.

Итог — флешка GPT с **единственной системой**:

```
P0 1М bios-boot   P1 2 GiB FAT32 «FLASHCARD» (QEMU + кнопки, она же ESP)
P2 остаток ext4       — Kubuntu (нативных запуск И QEMU-кнопка = та же система)
```

Новые заводские образы: диск 28 GiB (`DiskSizeGb=28`) для совместимости с
обычными флешками на 32 GB, ESP 2 GiB, корневой раздел ~26 GiB. Отдельная
подтверждённая флешка размером 31042043904 байт после изменения разметки имеет
корневой раздел ~26.9 GiB: он использует и хвост носителя за пределами 28 GiB.
Изменение относится только к будущим сборкам; существующие `.img`/`.qcow2`
не меняются. Описания 7 GiB ESP в старых тестах и резервных документах исторические.

- **Нативная загрузка** — выбрать флешку в boot-меню (UEFI/BIOS) на любом ПК.
- **`run-qemu.bat`** (на P1) — открыть систему флешки в QEMU. Требует прав
  администратора (UAC); при закрытом UAC — используйте нативную загрузку.
- Артефакты `virtual-disk.img/.qcow2` остаются на ПК для **клонирования** флешки.

Подробности: [`docs/два-тома.md`](docs/два-тома.md)

## Способ A — сборка кастомного ISO (Linux)

Требования: Ubuntu, ~26 ГБ места, sudo, интернет.

```sh
make prepare            # установка утилит сборки (xorriso, squashfs-tools и др.)
make iso                # основная сборка -> custom-kubuntu.iso (+ SHA256)
make clean              # удаление временных папок
make lint               # проверка синтаксиса bash-скриптов
```

Улучшения по сравнению с оригиналом: параметризуемая версия и SHA256-проверка
ISO, продолжаемое скачивание (`wget -c`), ранняя проверка места, корректное
размонтирование chroot по `trap`, пакеты из `packages.list`, VS Code/.NET из
репозитория Microsoft с проверкой подписи.

## Альтернативная сборка вручную (Windows, способ A)

Для кастомного ISO или qcow2 вручную:

1. `win\create-virtual-disk.bat` — виртуальный диск (qcow2).
2. `win\setup.bat` — установка из ISO в QEMU (вручную, в окне).
3. `win\convert-disk.bat` — конвертация qcow2 → raw.
4. `win\write-image.bat` — запись raw на флешку (от администратора).
5. `win\run-from-usb.bat` — запуск из файла-образа (без прав, файловый режим).

## Использование на учебных ПК

| ПК | Нативная загрузка | `run-qemu.bat` (P1) |
|---|---|---|
| Свой/свободный (admin есть) | ✅ | ✅ (UAC) |
| Учебный, boot-меню доступно | ✅ | ❌ (UAC закрыт) |
| Учебный, boot-меню закрыто | ❌ | ❌ |

Полностью «бесправный» вариант — `win\run-from-usb.bat` (**файловый** режим из
qcow2/raw). Это копия системы на обычной FAT-флешке — используется как резервный
сценарий, где закрыто всё. Подробности:
[`docs/учебные-ПК.md`](docs/учебные-ПК.md)

## Примечания

- SDDM/KDE — привычный интерфейс для пользователей Windows.
- Статус: PowerShell-скрипты писались без доступного на машине `pwsh` — первый
  прогон выполняется на Windows-машине с правами администратора.

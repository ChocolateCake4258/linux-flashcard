# LinuxFlashcard

[![Checks](https://github.com/ChocolateCake4258/linux-flashcard/actions/workflows/shellcheck.yml/badge.svg)](https://github.com/ChocolateCake4258/linux-flashcard/actions/workflows/shellcheck.yml)

Переносимая учебная Linux-система: **Debian 13 + XFCE**, языки программирования,
IDE, базы данных и офисные приложения. Одна установка на USB используется для
запуска из Windows в QEMU и для нативной загрузки через UEFI.

## Быстрый старт на Windows

1. Откройте [Releases](https://github.com/ChocolateCake4258/linux-flashcard/releases)
   и скачайте **`linux-flashcard-<версия>-windows.zip`** из нужного выпуска.
2. Полностью распакуйте ZIP в каталог на локальном **NTFS-диске с достаточным местом**.
3. Подключите USB от 32 ГБ и запустите **`START.bat`**.
4. Выберите USB по модели/serial, подтвердите стирание словом `yes` и разрешите UAC.
5. Дождитесь автоматической сборки, записи и сообщения о полной проверке.

**Результат — готовая флешка.** CHECK.bat отдельно проверяет комплектность архива.

Python и QEMU заранее устанавливать не нужно. Входные файлы скачиваются и
проверяются автоматически; установка программ и загрузочные проверки выполняются
на компьютере до записи USB. Закрытая сборка продолжается повторным запуском.

**Рабочие файлы создаются рядом с распакованным проектом в `LinuxFlashcard-work`.**
По умолчанию используется тот же диск, куда распакован ZIP. Автоматического
переключения на системный диск нет. Для выбора другого места используйте
`START.bat -Workspace <новый каталог>`.

## Требования

- Windows 10/11 **x64**, Windows PowerShell 5.1 и интернет для первоначальной сборки.
- Права администратора для подготовки виртуального диска и записи USB.
- USB от 32 ГБ; выбранный носитель будет полностью стёрт.
- Для 32-ГБ USB — около **70 ГБ свободного места на одном локальном NTFS-диске**.
- Минимум 4 ГБ свободной RAM; для полного набора предпочтительно 3–6 ГБ гостю
  плюс 2 ГБ резерва Windows. WHPX используется при доступном Windows-гипервизоре.
- Нативная загрузка — x86-64 UEFI на совместимом ПК.

### Поэтапное освобождение места

После проверки ISO удаляются его временные каталоги. После проверенного переноса
Linux RAW и VARS внутрь NTFS-макета отдельные исходные файлы удаляются.
Фиксированный VHD публикуется как RAW без второй полной копии: проверяются footer,
GPT и SHA данных, сохраняется recovery receipt, затем удаляется только 512-байтный
footer и файл переименовывается. Прерывание этой операции допускает продолжение.
Пиковая проверка места использует формулу:

```text
26 GiB + фактическая ёмкость USB + 6 GiB
```

Для типового 32-ГБ носителя это примерно 65,4 ГБ; рекомендуется 70 ГБ. Для больших
USB требование рассчитывается по их фактической ёмкости. Внутренняя Linux-система
остаётся 26 ГиБ. Готовый RAW, проверенные входы, runtime и receipts сохраняются
для продолжения и повторной записи. `-KeepIntermediates` оставляет все промежуточные
образы и отдельную конвертацию; этот режим требует около 100 ГБ для 32-ГБ USB.

## Что находится в архиве

- `START.bat` — автоматическая подготовка физической USB;
- `BUILD-IMAGE.bat` — полный выпуск файла-образа без выбора и записи USB;
- `CHECK.bat` — автономная проверка скачанного пакета;
- `win/` — поддерживаемый Windows-конвейер и установочные материалы;
- `docs/` — пользовательские инструкции;
- `RELEASE-MANIFEST.json` — длины и SHA256 всех файлов выпуска.

Собранная ОС и персональные данные в исходный ZIP не входят.

## Использование готовой флешки

- `run-linux.bat` — обычный TCG, без администратора Windows;
- `run-linux-accelerated.bat` — аппаратный WHPX;
- `enable-acceleration.bat` — первоначальная явная настройка WHPX;
- `backup-system.bat` / `restore-system.bat` — копия и восстановление комплекта.

Первый вход предлагает задать личный пароль непосредственно внутри Linux.
Между сменой режимов штатно выключайте Linux. Программы и проекты находятся
в общем `linux.img.vtoy`; постоянные VARS сохраняются рядом. Логи запуска —
в каталоге `logs` комплекта; временные данные процессов размещаются в его
рабочем каталоге, без записи в профиль Windows-пользователя.
